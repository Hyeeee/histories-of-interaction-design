# Week 3 · Paper Controller

**Pop-up Desk Lamp.** A paper pop-up card with a lamp you can raise and fold. A webcam reads two ArUco markers (js-aruco): ID 1 on the back page tells the page the card is there, ID 2 on the lamp shade shows up only when the lamp stands. How square the lamp marker looks sets the brightness, so the lamp works as a toggle and a slider.

- Lamp up → room lights up, warm chord and switch click
- Halfway → dimmed, each brightness step plays a note like a dimmer
- Folded flat → night, crickets come back

Readings: Clement Zheng, *Printed Paper Markers* · Mark Weiser, *A Computer for the 21st Century*

Print the card with `print-template.html` at 100% on cardstock.
